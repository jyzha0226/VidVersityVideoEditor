# 🚀 Website Deployment Guide

📋 Preparation:
Make sure you already have a `dist/` directory — this contains the final build of your website.

💡 Deploy to Cloud Platforms Recommended:

🌟 Vercel (vercel.com) – Easiest

1. Visit vercel.com and sign up.
2. Click “New Project”.
3. Select “Browse All Templates” → “Static”.
4. Drag and drop the `dist/` folder into the upload area.
5. Enter a project name and click “Deploy”.
6. Within a few minutes, you will receive a free HTTPS URL.

☁️ Cloudflare Pages (pages.cloudflare.com) – Fastest

1. Visit pages.cloudflare.com and log in.
2. Click “Create a project” → “Upload assets”.
3. Compress the `dist/` folder into a ZIP file.
4. Upload the ZIP file.
5. Set the project name and click “Deploy site”.
6. Enjoy global CDN acceleration.

🔥 Netlify (netlify.com) – User-friendly

1. Visit netlify.com and sign up.
2. Drag and drop the `dist/` folder onto the upload area on the homepage.
3. Wait for the upload to complete.
4. You will receive a random domain name, which can be customised in the settings.

📘 GitHub Pages (pages.github.com) – Free and Reliable

1. Create a new repository on GitHub.
2. Upload the contents of the `dist/` folder to the repository.
3. Go to Repository Settings → Pages.
4. Select “Deploy from a branch” → main branch.
5. Access your website at `username.github.io/repository-name`.

---

🔧 Advanced Deployment For Developers:

Git-based Automatic Deployment

1. Push the entire project, including the source code, to GitHub or GitLab.
2. Connect your repository to Vercel or Netlify.
3. Configure the build settings:

   * Build command: `npm run build`
   * Publish directory: `dist`
   * Node.js version: 16.x or higher
4. Every push will automatically trigger a new build and deployment.

Traditional Server Deployment
If you have your own server:

1. Upload all files inside the `dist/` directory to the server’s web root directory.
2. Make sure the server supports static file hosting.
3. Access the website through your domain name.

---

💰 Pricing Information:

* Vercel: The free plan is sufficient for personal use.
* Cloudflare Pages: Completely free with no major limitations.
* Netlify: The free plan includes 100GB bandwidth per month.
* GitHub Pages: Completely free with 100GB bandwidth per month.

---

🎯 Recommendation:

* Beginners: Vercel or Netlify drag-and-drop upload
* Speed priority: Cloudflare Pages
* Long-term projects: GitHub Pages
* Developers: Git-based automatic deployment

---

⚡ Tips:

* All platforms provide free HTTPS certificates.
* You can connect a custom domain, although some platforms may require a paid plan.
* After deployment, test your website on different devices.

---

🆘 Troubleshooting:

1. Make sure you upload the contents of the `dist/` folder, not the entire project.
2. Make sure `index.html` is located in the root directory.
3. Check the error logs on the hosting platform.
4. Make sure all files have been uploaded correctly.




🚀 网站部署指南
===========================

📋 准备工作：
确保您已经拥有 dist/ 目录 — 这包含了您网站的最终构建

💡 部署到云平台（推荐）：

🌟 Vercel (vercel.com) – 最简单
1. 访问 vercel.com 并注册
2. 点击“New Project”
3. 选择“Browse All Templates” → “Static”
4. 拖放 dist/ 文件夹到上传区域
5. 输入项目名称，点击“Deploy”
6. 几分钟内即可获得免费 HTTPS URL！

☁️ Cloudflare Pages (pages.cloudflare.com) – 最快
1. 访问 pages.cloudflare.com 并登录
2. 点击“Create a project” → “Upload assets”
3. 压缩 dist/ 文件夹
4. 上传压缩文件
5. 设置项目名称，点击“Deploy site”
6. 享受全球 CDN 加速！

🔥 Netlify (netlify.com) – 用户友好
1. 访问 netlify.com 并注册
2. 将 dist/ 文件夹拖放到主页上传区域
3. 等待上传完成
4. 您将获得一个随机域名（可在设置中自定义）

📘 GitHub Pages (pages.github.com) – 免费且可靠
1. 在 GitHub 上创建一个新仓库
2. 将 dist/ 文件夹的内容上传到仓库
3. 前往仓库设置 → Pages
4. 选择“Deploy from a branch” → 主分支
5. 在 username.github.io/repository-name 访问您的网站

---

🔧 高级部署（适合开发者）：

基于 Git 的自动部署
1. 将整个项目（包括源代码）推送到 GitHub/GitLab
2. 将您的仓库连接到 Vercel/Netlify
3. 配置构建设置：
   - 构建命令：npm run build
   - 发布目录：dist
   - Node.js 版本：16.x 或更高
4. 每次推送将自动触发构建和部署

传统服务器部署
如果您有自己的服务器：
1. 将 dist/ 目录内的所有文件上传到服务器的 web 根目录
2. 确保服务器支持静态文件托管
3. 通过您的域名访问网站

---

💰 价格信息：
- Vercel：免费计划足够个人使用
- Cloudflare Pages：完全免费，无限制
- Netlify：免费计划包含 100GB 带宽/月
- GitHub Pages：完全免费，100GB 带宽/月

---

🎯 推荐：
- 初学者：Vercel 或 Netlify（拖放上传）
- 速度优先：Cloudflare Pages
- 长期项目：GitHub Pages
- 开发者：基于 Git 的自动部署

---

⚡ 提示：
- 所有平台提供免费 HTTPS 证书
- 您可以绑定自定义域名（有些需要付费计划）
- 部署后，在不同设备上测试您的网站

---

🆘 故障排除：
1. 确保上传的是 dist/ 的内容，而不是整个项目
2. 确保 index.html 在根目录
3. 查看托管平台上的错误日志
4. 确保所有文件已正确上传
